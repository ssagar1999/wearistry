# Wearistry (कथा)

India's easy pre-loved fashion marketplace: buy, sell and swap clothes, plus Threads for showing finds, asking for pieces and offering swaps. Prices in ₹, shipping within India only.

## Repository layout

| Folder | What it is | Start here |
| --- | --- | --- |
| [`frontend/`](frontend/) | Next.js 15 web app (TypeScript, Tailwind) | [frontend/README.md](frontend/README.md) |
| [`backend/`](backend/) | Express 5 API (Node.js, MongoDB). Foundation done; features are being moved here from the frontend | [backend/README.md](backend/README.md) |

Other files at the root:

- `compose.yaml`: runs the app with Docker (see [teachdockerfile.md](teachdockerfile.md))
- `CLAUDE.md`: engineering standards for this repo
